License Activation

When you launch TGMarketing.exe for the first time, the activation wizard opens automatically. Activation requires a one-time internet connection to verify your purchase.

  1. Find your CodeCanyon purchase code

    Check your Envato purchase confirmation email — the purchase code is a UUID in the format xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx. You can also find it by logging into your Envato account → Downloads → find this item → "License certificate & purchase code".

  2. Enter the purchase code in the activation wizard

    The Purchase Code tab is selected by default. Paste your code into the field.

  3. Click "Activate"

    The app contacts Envato to verify your purchase, then saves a local activation. This takes a few seconds and only needs internet once.

  4. The app opens automatically

    All future launches skip the wizard — the activation is remembered on this machine.

Each purchase = one device. Your license is locked to the machine where you first activated it. No internet is needed after the initial activation.

Switching computers? Delete license.dat from the app folder on the old machine, then re-activate on the new machine using the same purchase code. Contact @Estjune on Telegram if you run into any issues.

First-Run Setup — Telegram API Credentials

After activation, a one-time setup wizard asks for your Telegram API credentials. These are stored locally in a .env file and are never shared.

  1. Go to my.telegram.org/apps

    Log in using your Telegram phone number. Telegram will send you a verification code.

  2. Create an application

    Click "Create new application". Fill in any App title and short name. Platform: Other. Click "Create application".

  3. Copy your API ID and API Hash

    You'll see them on the page. Paste the API ID (a number) and API Hash (a hex string) into the wizard fields.

  4. Click "Save & Launch"

    The app saves the credentials and opens the main interface.

You only do this once. If you ever need to change the credentials, edit the .env file in the app folder.

Adding Telegram Accounts

Go to Accounts → Add Account to authenticate a Telegram phone number. Each account creates a local session file used for scraping and campaigns.

  1. Enter the phone number

    Use international format, e.g. +251912345678 or +1 555 0100.

  2. Click "Send Code"

    Telegram sends a verification OTP to that phone or the Telegram app on that device.

  3. Enter the OTP

    Paste the code from Telegram. If the account has two-factor authentication (2FA) enabled, you'll be prompted for the 2FA password next.

  4. Account appears as "active"

    The session is saved locally. You can now use this account for scraping and campaigns.

Recommendation: Use accounts that have a history in Telegram — at least a few weeks old with prior group activity. Brand-new accounts are more likely to trigger Telegram's spam detection during mass DM/invite campaigns.

Click New Scrape in the sidebar. The wizard has three steps: Source → Filters → Config.

The app automatically normalises any URL or username format — you don't need to worry about adding or removing the @ sign.

If a standard Group/Channel scrape encounters a hidden member list mid-run, it automatically falls back to Msg Scan mode without any user action.

Config options

  • Max members: Set a cap. Use 0 for no limit (scrape all available members).
  • Request delay: Seconds between API page fetches. Default 1.5s is safe. Lower values are faster but increase flood-ban risk.
  • Account to use: Select which of your authenticated accounts performs the scrape.

Hidden Group Bypass — Message Scan

Many supergroups restrict who can see the member list. The tool handles this with two layered techniques:

  1. Message history scan — iterates through every message ever posted in the chat and records each unique sender. Anyone who has typed even one message is captured.
  2. Reactions scan — after the message scan, checks the 100 most recent posts for emoji reactions. Every user who reacted to any of those posts is added to the results, even if they never posted a message.

This combination finds active members that standard participant listing cannot reach.

Limitation: Silent lurkers who have never posted or reacted cannot be discovered through Msg Scan. This method finds participants, not the full member list.

Adds scraped users directly to a Telegram group or channel using the official InviteToChannel API.

Requirements for Mass Invite

  • The account running the campaign must be an admin of the target group.
  • The target group must accept new members (not closed/private without invite links).
  • Targets must have a known tg_id — users without one are skipped.

SMS Campaign

Sends SMS messages to phone numbers in your scraped list using the AfroMessage gateway. Designed for the Ethiopian and broader African market.

Setup

  1. Get an AfroMessage account

    Register at afromessage.com and go to Dashboard → API Keys.

  2. Enter credentials in Settings

    In the app, go to Settings → AfroMessage. Enter your API Token and optional Sender ID (your registered brand name). Click "Save Afro Settings".

  3. Create an SMS campaign

    Go to Campaigns → New Campaign → SMS Campaign. Select a source job that has phone numbers (use "Has phone" filter when scraping, or import a CSV with phone numbers).

SMS campaigns use the {name} placeholder the same way as Mass DM. The default limit is 500 SMS/day with 1–3s between sends.

Scrape the right list for SMS

For SMS to work, your source job must contain phone numbers. To maximise phone number coverage:

  • Scrape your own Contacts (they always have phone numbers)
  • Use the "Has phone" filter when scraping a group
  • Import a CSV that already contains a phone column

Results & Search

After a scrape completes, click Results in the sidebar (or the "View Results" button on the job). The results table shows:

  • Telegram ID — unique numeric ID
  • Username — @handle (clickable)
  • Full name
  • Phone — when available
  • Flags — Standard / Verified / Premium
  • Scraped at — timestamp

Use the search box at the top to filter by username or name. Toggle Verified or Premium to narrow to those subsets. Results are paginated — 50 rows per page.

Click Export to download the full result set as CSV or JSON.

Merge & Export

Go to Merge Files to combine results from multiple scrape jobs into a single file.

  1. Select jobs

    Tick the jobs you want to combine. Click "Select all" to include everything.

  2. Toggle deduplication

    Remove duplicates is on by default. It deduplicates by Telegram ID — if the same user appears in two jobs, only the first occurrence is kept.

  3. Preview

    Click Preview Dedup Count to see the raw total, unique count, and duplicate count before merging.

  4. Choose output format

    CSV (Excel-compatible) or JSON.

  5. Click "Merge & Download"

    The file is saved to your Downloads folder and opened automatically.

The merged file includes a source column showing which job each user came from (e.g. @crypto_group).

Multi-account pool for campaigns

When creating a campaign, you can select multiple accounts from the account selector. The campaign engine:

  1. Starts with the first account in the pool.
  2. Tracks daily actions per account in the database (resets at midnight).
  3. Automatically switches to the next account when the current one hits its daily limit or receives a PEER_FLOOD error.
  4. Stops the campaign if all accounts in the pool are exhausted.

Daily action counts survive app restarts — they are persisted in telescrap.db and reset at midnight automatically.

Removing an account

Click Remove. This deletes the session file from disk and removes the account from the database. The action is irreversible — you will need to re-authenticate the phone number to add it again.

Anti-Ban Safety System

Every campaign runs through a multi-layer protection engine. All of this is automatic — you do not need to configure it manually beyond setting your preferred limits.

✓

Daily action limits per account

Mass DM: 40/day. Mass Invite: 30/day. SMS: 500/day. Stored in the database and survive app restarts. Limits reset at midnight.

✓

Random jitter delays

Each action waits a random number of seconds between your configured min and max. This mimics human behaviour and avoids the rigid robot pattern that Telegram's spam detection looks for.

✓

PEER_FLOOD auto-stop & account rotation

PEER_FLOOD is Telegram's signal that an account is being flagged for spam. When detected, the current account is immediately suspended from the campaign and the next account in the pool takes over. If no accounts remain, the campaign stops.

✓

FloodWait handling

When Telegram requests a mandatory wait (e.g. "wait 120 seconds"), the tool waits exactly that long before continuing. If the FloodWait is longer than 5 minutes (300 seconds), the account is treated the same as PEER_FLOOD — rotated out of the pool.

✓

Graceful user skipping

Users with privacy restrictions, deactivated accounts, channel bans, or who are in too many groups are silently counted as "failed" and skipped. The campaign does not crash or stop for individual user errors.

✓

Immediate cancel

Clicking Cancel on any running campaign stops it cleanly — the current jitter delay is interrupted second-by-second and the campaign status is set to "cancelled".

Disclaimer: Even with these protections, mass DM and invite campaigns carry inherent risk of account restriction. Always use accounts with prior Telegram activity. The authors are not responsible for account restrictions caused by campaign usage. Use responsibly.

Frequently Asked Questions

Do I need to install Python?

No. The TGMarketing.exe is fully self-contained — it bundles the Python runtime, FastAPI server, Telethon library, and the entire UI. Just double-click and run.

Why does a group show "Member list is hidden"?

Some supergroups restrict the participant list to admins only. Use Msg Scan as the source type instead — it reads message history and reactions to discover active members without needing member list access. The tool also falls back to Msg Scan automatically when it encounters a restricted list.

Can I run multiple campaigns at the same time?

It is not recommended. Running parallel campaigns on the same account pool multiplies action counts and increases the risk of PEER_FLOOD. Run campaigns sequentially.

Will my Telegram account get banned?

Scraping is generally very safe. The risk comes from mass DM and invite campaigns. Follow the recommended daily limits (40 DMs, 30 invites per account) and use accounts that have been active on Telegram for at least a few weeks.

Where is all my data stored?

Everything is in the app folder: telescrap.db (scraped members, job history, campaign history), sessions/ (Telegram session files), and .env (API credentials). Nothing is uploaded anywhere.

How do I back up my data?

Copy telescrap.db and the sessions/ folder to another location. These two items contain all your data and sessions.

The app window doesn't open after double-clicking

Check if another process is using port 8000. If so, end it. Alternatively, wait 10–15 seconds — the server can take a moment to start. The window should appear automatically.

Can I scrape private groups?

You must already be a member of any group you want to scrape. If the group is invite-only and you're not a member, the tool cannot access it.

How do I update to a new version?

Extract the new version to the same folder, overwriting the old TGMarketing.exe. Your .env, telescrap.db, sessions/, and license files are all preserved.

Can I use a proxy?

Not in the current version. Proxy support is planned for a future update. Contact @Estjune on Telegram for custom integration inquiries.

My license says "machine mismatch"

Your purchase code was already activated on a different computer. To move it to this machine: delete license.dat from the app folder, re-launch, and enter your purchase code again. If you need help, contact @Estjune on Telegram.
